# 设计文档：用户管理

## 设计基底

**主题参考**: `src/themes/vercel/DESIGN.md`

本原型采用 Vercel 的开发者平台设计语言，具有以下核心特征：

### 视觉基础

- **色彩系统**: 黑白二元对比 (`#171717` 墨黑 + `#ffffff` 纯白背景)
- **表面层级**: 
  - `canvas` (#ffffff) — 卡片和模态框表面
  - `canvas-soft` (#fafafa) — 页面背景
  - `primary` (#171717) — 主要操作按钮和反转区域
- **强调色**: `link` (#0070f3) 用于链接和成功状态

### 排版

- **字体族**: Geist (几何无衬线字体) 用于所有界面文本，Geist Mono 用于技术标签
- **标题**: `display-md` (24px / 600 / -0.96px 字间距) 用于页面标题
- **正文**: `body-sm` (14px / 400) 用于表格和导航，`body-md` (16px / 400) 用于描述文本
- **按钮**: `button-md` (14px / 500) 用于操作按钮
- **原则**: 负字间距是品牌声音的一部分，标题使用句子式大小写

### 形状

- **圆角系统**:
  - `sm` (6px) — 输入框和小按钮的基础圆角
  - `md` (8px) — 卡片和容器
  - `lg` (12px) — 较大的卡片容器
  - `pill` (100px) — 营销规模的 CTA 按钮
  - `full` (9999px) — 图标按钮和头像
  
### 间距

- 基础单位: 4px
- 常用间距: `xs` (8px), `sm` (12px), `md` (16px), `lg` (24px), `xl` (32px)
- 卡片内边距: `lg` (24px)
- 页面边距: `lg` (24px) 桌面端，`md` (16px) 移动端

### 阴影与深度

- **Level 1 — 内嵌发丝线**: `0 0 0 1px rgba(0,0,0,0.08)` — 默认卡片边框
- **Level 3 — 柔和堆叠**: 多层小偏移阴影 + 内嵌发丝线 — 表格容器
- **堆叠原则**: 使用多个小偏移的阴影层叠，而非单一的重阴影

## 组件规范

### 顶部栏 (Nav Bar)

- 高度: 64px
- 背景: `canvas` (#ffffff)
- 边框: 底部 1px `hairline` (#ebebeb)
- 内边距: `sm` (12px) 垂直，`lg` (24px) 水平
- 元素:
  - 菜单按钮: 图标按钮，圆角 `md`
  - 页面标题: `body-md-strong` (16px / 500)
  - 用户头像: 32px 圆形，圆角 `full`

### 内容区头部

- 主标题: `display-md` (24px / 600 / -0.96px) 配合 `ink` (#171717)
- 副标题: `body-md` (16px / 400) 配合 `ink-muted` (#d0d6e0)
- 间距: 标题与副标题间隔 `xs` (8px)，头部与操作栏间隔 `md` (16px)

### 搜索框

- 基于 `form-input` 组件
- 高度: 40px
- 背景: `canvas-soft` (#fafafa)
- 边框: 1px `hairline` (#ebebeb)
- 圆角: `sm` (6px)
- 内边距: 8px 12px，左侧留出 36px 给搜索图标
- 排版: `body-sm` (14px)
- 焦点状态: 边框改为 `link` (#0070f3)，添加 `0 0 0 2px rgba(0,112,243,0.2)` 焦点环

### 按钮

**主要按钮 (Primary)**:
- 基于 `button-primary-sm`
- 背景: `primary` (#171717)
- 文本: `on-primary` (#ffffff)
- 排版: `button-md` (14px / 500)
- 圆角: `pill` (100px)
- 内边距: 0px `xs` (8px)
- 高度: 约 32px

**次要按钮 (Secondary)**:
- 基于 `button-secondary-sm`
- 背景: `canvas` (#ffffff)
- 文本: `ink` (#171717)
- 边框: 1px `hairline` (#ebebeb)
- 其他参数同主要按钮

### 数据表格

- 基于 `ex-data-table-cell` 规范
- 容器:
  - 背景: `canvas` (#ffffff)
  - 边框: 1px `hairline` (#ebebeb)
  - 圆角: `lg` (12px)
  - 阴影: Level 3 柔和堆叠
  
- 表头:
  - 背景: `canvas-soft` (#fafafa)
  - 排版: `caption` (12px / 400 / 大写)，使用 Geist 字体
  - 文本色: `body` (#4d4d4d)
  - 内边距: `sm` (12px) 垂直，`lg` (24px) 水平
  - 底部边框: 1px `hairline`
  
- 表体行:
  - 背景: `canvas` (#ffffff)
  - 排版: `body-sm` (14px / 400)
  - 内边距: `md` (16px) 垂直，`lg` (24px) 水平
  - 行分隔线: 1px `hairline`
  - 悬停状态: 背景改为 `canvas-soft-2` (#f5f5f5)
  
- 用户单元格:
  - 头像: 32px 圆形，背景 `canvas-soft-2`，边框 1px `hairline`
  - 姓名: `body-sm-strong` (14px / 500)
  - 间距: 头像与姓名间隔 `sm` (12px)

- 状态单元格:
  - 状态点: 8px 圆形
  - 活跃: `success` (#0070f3)
  - 停用: `body` (#4d4d4d)
  - 间距: 状态点与文本间隔 6px

### 抽屉 (Drawer)

- 基于 `ex-modal-card` 规范
- 宽度: 400px
- 背景: `canvas` (#ffffff)
- 左边框: 1px `hairline` (#ebebeb)
- 阴影: Level 5 模态框阴影
- 动画: 从右侧滑入，持续 0.2s ease

**抽屉头部**:
- 内边距: `lg` (24px)
- 底部边框: 1px `hairline`
- 标题: `display-sm` (20px / 600 / -0.6px)
- 关闭按钮: 图标按钮，圆角 `md`

**抽屉内容**:
- 内边距: `lg` (24px)
- 滚动: 内容超出时垂直滚动

**抽屉底部**:
- 内边距: `lg` (24px)
- 顶部边框: 1px `hairline`
- 按钮排列: 右对齐，间距 `sm` (12px)

### 表单元素

**输入框**:
- 基于 `form-input` 组件
- 高度: 40px
- 背景: `canvas-soft` (#fafafa)
- 边框: 1px `hairline` (#ebebeb)
- 圆角: `sm` (6px)
- 内边距: 8px 12px
- 排版: `body-sm` (14px)
- 焦点状态: 边框改为 `link`，焦点环 `0 0 0 2px rgba(0,112,243,0.2)`

**标签**:
- 排版: `body-sm-strong` (14px / 500)
- 文本色: `ink` (#171717)
- 间距: 标签与输入框间隔 `xs` (8px)

**选择框**:
- 参数同输入框
- 添加指针光标

**单选按钮**:
- 尺寸: 16px
- 强调色: `primary` (#171717)
- 文本: `body-sm` (14px)
- 间距: 单选项之间间隔 `md` (16px)

## 交互规范

### 悬停状态

- 按钮: 主按钮背景稍微变亮，次要按钮背景改为 `canvas-soft`
- 表格行: 背景改为 `canvas-soft-2`
- 输入框: 无悬停变化，仅在焦点时显示

### 焦点状态

- 输入框: 边框改为 `link` (#0070f3)，添加 2px 焦点环
- 按钮: 添加焦点环（可访问性）
- 表格行: 可点击的行在焦点时显示外边框

### 动画

- 抽屉: 0.2s ease 滑入/滑出
- 过渡: 所有颜色和背景变化使用 0.15s ease
- 淡入: 叠加层使用 0.2s ease 淡入

## 响应式策略

### 断点

- 移动端: < 600px
- 平板: 600-959px
- 桌面: ≥ 960px

### 移动端适配 (< 768px)

- 搜索框: 占据整行宽度
- 按钮: 全宽度或堆叠排列
- 抽屉: 全屏宽度
- 表格: 启用横向滚动，最小宽度 600px
- 页面边距: 从 `lg` 降为 `md` (16px)

## 设计原则

1. **黑色墨水是转化目标** — `primary` (#171717) 专用于主要 CTA
2. **负字间距是品牌声音** — 保持显示尺寸的负字间距
3. **堆叠阴影而非重阴影** — 使用多层小偏移 + 内嵌发丝线
4. **几何字体 + 等宽技术标签** — Geist 用于界面，Geist Mono 用于代码
5. **句子式大小写标题** — 避免全大写（除了表格标题使用小型大写字母）
6. **100px pill 用于营销，6px 方角用于应用** — 在同一界面保持一致的圆角规模
