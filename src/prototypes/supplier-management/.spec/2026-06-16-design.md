## 2. 视觉设计规范

### 2.1 顶部操作栏

**容器**：
- 背景：`{colors.canvas}` (#ffffff)
- 高度：80px
- 内边距：`{spacing.md}` 16px 上下，`{spacing.lg}` 24px 左右
- 底部边框：1px solid `{colors.hairline}` (#ebebeb)

**搜索框** (`form-input`):
- 宽度：320px
- 高度：40px
- 圆角：`{rounded.sm}` 6px
- 边框：1px solid `{colors.hairline}`
- Placeholder："搜索供应商名称、编码..."
- 字体：`{typography.body-sm}` (14px)

**快速筛选按钮组**：
- 使用 `button-secondary-sm` 样式
- 圆角：`{rounded.pill}` 100px（pill 形状）
- 间距：`{spacing.xs}` 8px
- 字体：`{typography.button-md}` (14px / 500)

**高级筛选按钮**：
- 样式：`button-secondary-sm`
- 图标：下拉箭头

**新增供应商按钮**：
- 样式：`button-primary-sm`
- 背景：`{colors.primary}` (#171717)
- 文字：`{colors.on-primary}` (#ffffff)
- 前置图标：+ 号

### 2.2 供应商卡片 (`card-marketing`)

**容器**：
- 背景：`{colors.canvas}` (#ffffff)
- 圆角：`{rounded.md}` 8px
- 内边距：`{spacing.lg}` 24px
- 阴影：Level 3 Soft Stack
  ```
  0px 2px 2px #0000000a, 
  0px 8px 8px -8px #0000000a,
  0 0 0 1px #00000014 inset
  ```
- 宽度：自适应（2列网格，gap: `{spacing.md}` 16px）
- Hover 状态：边框变为 `{colors.hairline-strong}` + 轻微上浮

**卡片内容结构**：
1. **标题行**：
   - 供应商简称：`{typography.display-sm}` (20px / 600)
   - 颜色：`{colors.ink}` (#171717)
   
2. **编码行**：
   - 供应商编码：`{typography.caption-mono}` (12px / 400)
   - 颜色：`{colors.body}` (#4d4d4d)
   
3. **标签行**：
   - 使用 `badge-secondary` 样式
   - 背景：`{colors.canvas-soft}` (#fafafa)
   - 文字：`{colors.body}` (#4d4d4d)
   - 圆角：`{rounded.full}` (9999px)
   - 内边距：`0px {spacing.xs}` (0px 8px)
   - 字体：`{typography.caption}` (12px / 400)
   - 间距：`{spacing.xxs}` 4px
   - 标签类型：分级、供应商标识、行业分类
   
4. **底部信息行**：
   - 状态指示器：色点 + 文字
   - 审核状态：绿色点 (已审批) / 橙色点 (审批中)
   - 地区：`{typography.body-sm}` (14px / 400)
   - 颜色：`{colors.mute}` (#888888)

**卡片选中状态**：
- 边框：2px solid `{colors.primary}` (#171717)
- 背景：`{colors.canvas-soft}` (#fafafa)

### 2.3 详情面板

**容器**：
- 背景：`{colors.canvas-soft}` (#fafafa)
- 内边距：`{spacing.xl}` 32px
- 固定定位（右侧）

**折叠分组 (Accordion)**：
- 每个分组：
  - 标题：`{typography.body-md-strong}` (16px / 500)
  - 图标：▾ 展开 / ▸ 收起
  - 分隔线：1px solid `{colors.hairline}` (#ebebeb)
  - 内边距：`{spacing.md}` 16px 上下

**详情字段**：
- 标签：`{typography.caption}` (12px / 400)，颜色 `{colors.mute}`
- 值：`{typography.body-sm}` (14px / 400)，颜色 `{colors.ink}`
- 行间距：`{spacing.xs}` 8px

**底部操作按钮**：
- [编辑]：`button-secondary-sm`
- [删除]：`button-secondary-sm`，文字颜色 `{colors.error}` (#ee0000)
- 间距：`{spacing.sm}` 12px

### 2.4 新增/编辑表单

当点击"新增"或"编辑"时，右侧详情面板切换为表单模式：

**表单容器**：
- 背景：`{colors.canvas}` (#ffffff)
- 圆角：`{rounded.lg}` 12px
- 内边距：`{spacing.xl}` 32px
- 阴影：Level 4 Float Stack

**表单字段** (`form-input`):
- 高度：40px
- 圆角：`{rounded.sm}` 6px
- 边框：1px solid `{colors.hairline}`
- 字体：`{typography.body-sm}` (14px)
- 标签字体：`{typography.body-sm-strong}` (14px / 500)
- 字段间距：`{spacing.md}` 16px

**必填标识**：
- 红色星号 `*`，颜色 `{colors.error}` (#ee0000)

**错误提示**：
- 字体：`{typography.caption}` (12px / 400)
- 颜色：`{colors.error}` (#ee0000)
- 位置：字段下方，间距 `{spacing.xxs}` 4px

**底部操作按钮**：
- [取消]：`button-secondary-sm`
- [保存]：`button-primary-sm`
- 间距：`{spacing.sm}` 12px

## 3. 交互设计

### 3.1 卡片交互

1. **默认状态**：
   - 首次进入页面，默认选中第一张卡片
   - 右侧显示该供应商的详细信息

2. **点击卡片**：
   - 卡片切换为选中状态（边框高亮）
   - 右侧详情面板更新为该供应商的信息
   - 页面平滑滚动到选中卡片位置（如需要）

3. **Hover 状态**：
   - 鼠标悬停时，卡片边框颜色变深
   - 轻微上浮效果（transform: translateY(-2px)）

### 3.2 筛选交互

1. **搜索框**：
   - 实时搜索（输入300ms后触发）
   - 匹配供应商全称、简称、编码

2. **快速筛选**：
   - 点击筛选按钮，显示下拉选项
   - 单选模式（审核状态、供应商状态、分级）
   - 选中后按钮显示当前筛选值

3. **高级筛选**：
   - 点击展开/收起高级筛选面板
   - 面板位置：顶部操作栏下方
   - 背景：`{colors.canvas-soft}` (#fafafa)
   - 内边距：`{spacing.lg}` 24px
   - 支持多选（地区、行业分类、供应商标识）

### 3.3 详情面板交互

1. **折叠分组**：
   - 默认展开"基本信息"分组
   - 其他分组默认收起
   - 点击标题行切换展开/收起状态
   - 动画：高度过渡 300ms

2. **编辑模式**：
   - 点击"编辑"按钮，面板切换为表单模式
   - 表单预填充当前数据
   - 点击"取消"返回详情模式（确认未保存）
   - 点击"保存"提交表单，成功后返回详情模式

3. **删除确认**：
   - 点击"删除"按钮，弹出确认对话框（`ex-modal-card` 样式）
   - 对话框内容："确定删除供应商「XXX」吗？此操作不可恢复。"
   - 按钮：[取消] [确定删除]

### 3.4 新增供应商

1. **点击"新增供应商"按钮**：
   - 左侧卡片区取消选中状态
   - 右侧详情面板切换为新增表单模式
   - 表单字段为空

2. **表单填写**：
   - 必填字段标红星
   - 实时验证（失焦时触发）
   - "是否生产"字段联动生产相关字段的必填状态

3. **提交**：
   - 点击"保存"，统一校验所有字段
   - 校验失败：滚动到第一个错误字段，显示错误提示
   - 校验成功：提交数据，成功后刷新列表，新增卡片自动选中

## 4. 响应式设计

### 4.1 桌面端（≥ 960px）
- 左侧卡片网格：2列
- 右侧详情面板：固定宽度 40%

### 4.2 平板端（600px - 959px）
- 左侧卡片网格：1列
- 右侧详情面板：固定宽度 50%

### 4.3 移动端（< 600px）
- 列表+详情切换为单列堆叠模式
- 点击卡片后，详情面板以全屏抽屉形式从底部弹出
- 抽屉可向下滑动关闭

## 6. 状态映射

### 6.1 审核状态
- **已审批**：绿色圆点 (#0070f3) + "已审批"文字
- **审批中**：橙色圆点 (#f5a623) + "审批中"文字

### 6.2 供应商状态
- **正常**：无特殊标识（默认状态）
- **异常**：红色圆点 (#ee0000) + "异常"文字

### 6.3 分级标签
- **AA级**：深色背景标签，显著标识
- **A级**：浅色背景标签
- **B级**：更浅背景标签
- **未分级**：不显示分级标签

### 6.4 供应商标识
- **重点**：蓝色标签
- **上市**：紫色标签
- **高新**：青色标签
- **电商**：品红标签

## 9. 设计资产

### 9.1 使用的 Vercel 组件
- `button-primary-sm` - 主要按钮（新增、保存）
- `button-secondary-sm` - 次要按钮（取消、编辑、删除）
- `card-marketing` - 供应商卡片
- `form-input` - 表单输入框
- `badge-secondary` - 标签
- `ex-modal-card` - 确认对话框
- `ex-empty-state-card` - 空状态卡片

### 9.2 颜色使用
- 主色：`{colors.primary}` (#171717) - 按钮、边框高亮
- 背景：`{colors.canvas}` (#ffffff) - 卡片、表单
- 次背景：`{colors.canvas-soft}` (#fafafa) - 页面、详情面板
- 文字：`{colors.ink}` (#171717) - 主要文字
- 次要文字：`{colors.body}` (#4d4d4d) - 说明文字
- 弱化文字：`{colors.mute}` (#888888) - 辅助信息
- 链接/成功：`{colors.link}` (#0070f3) - 链接、成功状态
- 错误：`{colors.error}` (#ee0000) - 错误提示、删除按钮
- 警告：`{colors.warning}` (#f5a623) - 审批中状态
- 分隔线：`{colors.hairline}` (#ebebeb) - 边框、分隔线

### 9.3 圆角使用
- 小按钮/输入框：`{rounded.sm}` 6px
- 卡片：`{rounded.md}` 8px
- 大卡片/对话框：`{rounded.lg}` 12px
- 标签/徽章：`{rounded.full}` 9999px
- Pill 按钮：`{rounded.pill}` 100px
