# 电厂基本信息管理 - 实现文档

**日期**: 2026-06-16  
**设计系统**: Vercel  
**数据源**: `src/resources/电厂表.json`

## 产品需求

### 目标用户
电厂管理人员，需要快速查询和浏览大唐集团下属电厂的基本信息。

### 核心任务
- 浏览电厂列表（120+条记录）
- 通过多维度筛选快速定位目标电厂
- 查看电厂详细信息

### 功能范围
1. **列表展示**: 单位名称、简称、所属分公司、装机容量、省份、城市
2. **搜索筛选**: 
   - 关键词搜索（名称/简称）
   - 省份筛选
   - 所属分公司筛选
   - 装机容量范围筛选
3. **详情查看**: 完整字段展示，包括经纬度、详细装机情况等

### 验收重点
- 筛选功能正常响应
- 列表数据正确展示
- 详情面板交互流畅

## 设计方案

### 设计基底
采用 **Vercel 主题** (`src/themes/vercel/DESIGN.md`)

**选择理由**:
- 专业的 B2B 工具风格，适合企业内部管理系统
- 黑白精确配色，信息密度高
- 表格和数据展示效果优秀

### 关键设计决策

1. **布局模式**: 列表-详情（List-Detail）
   - 左侧表格展示核心字段
   - 右侧侧边栏显示详情（按需展开）

2. **信息层级**:
   - 一级：单位名称（加粗）
   - 二级：装机容量、省份城市
   - 三级：所属分公司（灰色）

3. **交互路径**:
   - 主路径：筛选 → 浏览列表 → 点击查看详情
   - 辅助：点击行 / 点击"查看详情"按钮均可打开详情

4. **视觉语气**:
   - 严格继承 Vercel 设计系统
   - 使用 Inter 字体
   - 极简阴影和边框
   - 6px/8px 圆角

5. **数据呈现**:
   - 使用真实数据（120条电厂记录）
   - 空状态提示"暂无符合条件的电厂数据"

## 设计假设

1. 装机容量单位统一为 MW
2. 经纬度仅在详情中展示
3. "详细装机情况"字段允许为空或数字类型（数据不统一）
4. 不需要分页（120条数据量可接受）
5. 筛选条件之间为 AND 关系
